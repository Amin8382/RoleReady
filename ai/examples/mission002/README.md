# Mission 002 synthetic functional fixtures

All CVs, job descriptions and the 18 question-bank entries were authored for
this demonstration. They contain no real candidate data and no scraped dataset.
Every bank record is explicitly TRAIN. `reviewed` defaults to false: these are
retrieval inspirations, not reviewed reference answers for scoring or SFT.

The three scenarios are Junior Data Analyst, Machine Learning Engineer and
Backend Developer. Each CV documents concrete academic projects and explicitly
does not evidence some job requirements. Those requirements should prompt
hypothetical questions, never fabricated experience or claims of missing ability.

These fixtures demonstrate functionality. They are not held-out evaluation
cases, a licensed external question corpus or evidence of human-validated quality.
